## 执行方式

```powershell
uv run python scripts/verify_live.py --article-url '实际文章链接'
# 或
uv run python scripts/verify_live.py --book-id MP_WXS_实际数字ID
```

脚本会真实添加所选公众号到微信读书书架并启用本地监控，然后真实执行 refresh、读取固定报告。任何前置环节失败都会停止依赖步骤，并保存失败记录；返回码 1，不标记通过。

通过条件：认证可用，远端书架回读确认目标订阅，本地清单保存成功，当轮采集包含目标账号的可用正文，且独立进程重读报告与当次结果一致。若无当轮目标正文则为 inconclusive，整体仍 not_passed；若扫描达到页数预算等限制则保留 partial，不伪装完整采集。

当轮已有正文但覆盖不足时仍执行报告持久化核对，collection 保持 partial，整体不升级为 passed。上述证据不证明历史文章完整、多日稳定、发现延迟或正文内容准确性。正文真实性及完整性还需要与手机可见原文核对，尚未完成的验证逐项保持未验证。
